# 💶 Budget & Expense Tracker

A simple personal budget tracker. No accounts, no server — everything is saved
locally in your browser.

## What it does

- **Set your income** — e.g. €2300 per month.
- **Fixed monthly costs** — add/edit/remove items (rent & food, stocks,
  pensioensparen, …). The total is calculated automatically.
- **Split what's left** — a slider divides your leftover money between
  **fun** and **saving**.
- **Quick expenses** — jot down spends in seconds (e.g. *store · €15 · beer*).
- **Monthly summary** — see income, fixed costs, fun spent, fun money left
  and how much is going to savings.

## How to use

Just open `index.html` in any browser. That's it.

Your data lives in the browser's `localStorage`, so it stays on the device you
use. Use the **Reset all** button to start fresh.

## Files

- `index.html` — page structure
- `styles.css` — styling
- `app.js` — logic & local storage
